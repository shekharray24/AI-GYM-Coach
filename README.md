# AI Real-time GYM Coach

AI Real-time GYM Coach is a computer-vision-based workout assistant that uses a live camera feed to analyze exercise movements, track repetitions, evaluate workout form, and provide AI-generated coaching feedback.

The application is built with Streamlit and Streamlit WebRTC for real-time video processing. MediaPipe Pose Landmarker is used to detect human body landmarks, while custom exercise detectors calculate movement metrics and repetition counts. Groq is used to generate natural-language coaching feedback, and gTTS converts the feedback into speech.

## Features

- Real-time human pose detection using MediaPipe
- Live camera processing with Streamlit WebRTC
- Automatic repetition counting
- Exercise-specific movement analysis
- Real-time form scoring
- Form correction feedback
- AI-generated coaching feedback using Groq
- Text-to-speech coaching using gTTS
- Workout progress tracking
- Set and repetition tracking
- Workout history stored using SQLite
- Simple username-based session system
- Metrics displayed for each supported exercise
- Responsive Streamlit interface

## Supported Exercises

1. Squats
2. Push-ups
3. Biceps Curls (Dumbbell)
4. Shoulder Press
5. Lunges

## Exercise Analysis

### Squats

The squat detector tracks:

- Knee angle
- Back angle
- Squat depth
- Repetitions

The system identifies whether the user reaches an appropriate squat depth and checks for excessive forward leaning.

### Push-ups

The push-up detector tracks:

- Elbow angle
- Body alignment
- Hip position
- Repetitions

The system checks whether the body remains aligned and identifies hip sagging or excessive hip elevation.

### Biceps Curls

The biceps curl detector tracks:

- Elbow angle
- Shoulder stability
- Swing detection
- Repetitions

The system identifies elbow drifting and excessive torso movement during curls.

### Shoulder Press

The shoulder press detector tracks:

- Elbow angle
- Arm extension
- Back arch
- Repetitions

The system evaluates arm extension and detects excessive or slight back arching.

### Lunges

The lunge detector tracks:

- Front knee angle
- Torso angle
- Balance status
- Repetitions

The system evaluates lower-body movement and checks whether the user maintains balance and an upright torso.

## Form Scoring

The project includes a form-scoring module that calculates a score from 0 to 100 based on exercise-specific posture and movement conditions.

The scoring system evaluates factors such as:

- Joint angles
- Body alignment
- Exercise depth
- Torso position
- Balance
- Movement stability

Along with the numerical score, the system generates corrective feedback messages for detected form problems.

## AI Coaching

The coaching pipeline uses the Groq API to generate short, natural coaching instructions.

The system can provide feedback for events such as:

- Workout started
- Set completed
- Workout completed
- Form issues detected
- Pose not detected

The coaching prompt is designed to produce concise and practical instructions suitable for being spoken aloud during exercise.

## Voice Feedback

Text generated by the AI coach is converted into speech using Google Text-to-Speech (gTTS).

The application dynamically generates audio for coaching messages and plays the generated voice feedback in the Streamlit interface.

## Installation

Clone the repository:

```bash
git clone https://github.com/shekharray24/AI-GYM-Coach.git
```

Move into the project directory:

```bash
cd AI-GYM-Coach
```

Create a virtual environment.

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Environment Variables

The application requires a Groq API key.

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
```

Do not commit the `.env` file to GitHub.

The application loads the key using environment variables and can also use Streamlit secrets when deployed.

## Running the Application

Start the Streamlit application with:

```bash
python -m streamlit run main.py
```

After starting the server, open the local Streamlit URL shown in the terminal, normally:

```text
http://localhost:8501
```

## How to Use

1. Open the application.
2. Enter a username to start a session.
3. Select an exercise from the workout plan.
4. Select the number of sets.
5. Select the target repetitions per set.
6. Click Start Workout.
7. Allow camera access when requested.
8. Position yourself so the camera can clearly detect your body.
9. Perform the selected exercise.
10. The system tracks repetitions, evaluates form, calculates a form score, and provides coaching feedback.
11. End the workout when the session is complete.
12. Workout information is stored in the local SQLite database and displayed in Workout History.

## AI Coaching Pipeline

### LLM Coach

The LLM coach sends workout events and detected form issues to the Groq API.

The current project uses:

```text
openai/gpt-oss-120b
```

for generating coaching responses.

### Text-to-Speech

The generated coaching message is converted into MP3 audio using gTTS.

### Voice Pipeline

The voice pipeline connects exercise events, form issues, the LLM coach, and text-to-speech.

It also includes cooldown handling to avoid repeatedly speaking the same form correction too frequently.

## Important Files

### `main.py`

The main Streamlit application. It handles:

- Application layout
- Session management
- Workout configuration
- Start and End Workout controls
- Camera interface
- Coaching feedback display

### `detectors/`

Contains exercise-specific movement and repetition detection logic.

### `services/vision/exercise_video_processor.py`

Handles:

- Video frame processing
- Pose landmark detection
- Skeleton rendering

- Form score calculation
- Latest metric storage

### `services/scoring/form_scorer.py`

Calculates the form score and produces corrective feedback.

### `services/coaching/llm.py`

Handles communication with the Groq API and generates coaching responses.

### `services/coaching/tts.py`

Converts coaching text into speech using gTTS.

### `services/coaching/voice_pipeline.py`

Connects exercise events, form issues, the LLM coach, and text-to-speech.

### `services/tracking/metrics.py`

Synchronizes video-processing metrics with Streamlit session state and manages workout progress and set completion.

### `services/persistence/exercise_repository.py`

Handles SQLite database initialization, user records, exercise records, and workout history.

## Limitations

The accuracy of pose detection and form analysis depends on camera quality, lighting, body visibility, camera angle, and the user's position within the frame.

The current form analysis is rule-based and uses predefined thresholds for each exercise. It should therefore be treated as a workout assistance tool rather than a replacement for professional fitness or medical advice.

Voice feedback depends on successful text-to-speech generation and network connectivity for gTTS.
